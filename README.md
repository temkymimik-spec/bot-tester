# 🚀 Трейдинг-бот (Telegram, aiogram 3)

Прогревающий бот-воронка для регистрации на Pocket Option:
пользователь проходит вопросы (возраст, стаж, капитал, цель) → получает
видео-гайд, текстовую инструкцию, реф-ссылку, промокод и ссылку на приватный канал.

**Без вебхука** — работает через long polling. **Без внешней БД** — всё хранится
в локальном файле `data/bot_data.json`. Хостинг — **Docker**.

## 📁 Файлы
- `bot.py` — сам бот (запуск `python bot.py`)
- `database.py` — локальное хранение (JSON)
- `funnel.py` — логика воронки
- `keyboards.py` — кнопки
- `config.py` — чтение `.env`
- `Dockerfile` / `docker-compose.yml` — деплой
- `data/` — БД (создаётся сама)
- `media/` — папка для роликов (видео грузится через бота)

## ⚙️ Установка (локально)
1. `pip install -r requirements.txt`
2. Создайте `.env` из `.env.example` и впишите:
   ```
   BOT_TOKEN=123:AA...          # токен от @BotFather
   ADMIN_IDS=111,222            # ваш Telegram id
   ```
3. `python bot.py`
   Или для быстрого старта: `./start.sh`

## 🐳 Docker-хостинг
1. Скопируйте `.env.example` → `.env`, заполните `BOT_TOKEN` и `ADMIN_IDS`.
2. Соберите и запустите:
   ```
   docker compose up -d --build
   ```
3. Логи: `docker compose logs -f bot`
4. Данные хранятся в `./data/` на хосте (переживают перезапуск контейнера).

## 🎛 Админка — прямо в боте (без веб-панели)
Всё меняется из Telegram, никакого вебхука/панели не нужно:

- `/admin` — меню админа
  - **📊 Статистика** — юзеры, прошедшие воронку
  - **⚙️ Настройки** — меняете **реф-ссылку, промокод, ссылку на канал, текст инструкции**:
    жмёте пункт → бот просит ввести новое значение → отправляете текст → сохранено ✅
  - **📤 Загрузить видео-гайд** — просто отправьте mp4 боту из-под админа
  - **🔄 Сброс юзера** — или команда `/reset <user_id>`

## 💸 Работа воронки
1. `/start` → «🚀 Начать прогревание»
2. Вопросы на кнопках: возраст → стаж → капитал → цель
3. Финал: текст-инструкция + реф-ссылка + промокод + ссылка на канал + видео-гайд

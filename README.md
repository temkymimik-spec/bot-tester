# PRO SIGNALS — Telegram-бот торговых сигналов для Pocket Option

Рабочий бот для стримов: юзеры подключаются по реф-ссылке, админ одобряет кнопкой, активированные получают сигналы мгновенно. Панель админа — полностью в кнопках.

## Что умеет

**Юзеры**
- Приветствие + инструкция: рега на Pocket Option по нашей ссылке → промокод БОНУС 50% → депозит от $10 → прислать Pocket ID → ждать одобрения.
- Кнопки «Отправить ID», «Как найти ID», «Написать админу».
- После активации получают сигналы в этот же чат автоматически.
- `/status` — свой статус.

**Админы (их может быть несколько)**
- `/admin` — панель в кнопках.
- 📝 **Новые заявки** — каждая заявка = кнопки ✅ Одобрить / ❌ Отклонить.
- 📊 **Статистика** — всего/активных/в ожидании/отклонённых + последние регистрации.
- 📡 **Сигналы** — вкл/выкл авто, «Сигнал сейчас», тест AI, выбор пары и интервала, выбор AI-провайдера.
- ⚙️ **Настройки** — реф-ссылка, промокод, контакт админа, мин. депозит, AI API Key, модель, Base URL.
- 💬 **Рассылка** — сообщение всем активированным.
- 👥 **Админы** — добавить/убрать (убирать может только владелец).

**Сигналы**
- Работают сразу, **без ключей и без денег**: встроенная FREE-стратегия (EMA 7/21 + RSI + импульс свечей).
- Можно подключить нейросеть: любой **OpenAI-совместимый** сервис (в т.ч. бесплатные) либо NeuroAPI.
- Свечи берутся бесплатно: Binance → Bybit → OKX (фолбэк автоматический).
- Данные в реальном времени, интервал настраивается (1–5 мин).

## Чем отличаются режимы AI

| Режим | Цена | Что это |
|---|---|---|
| **Strategy (FREE)** ⚡ | $0 | Встроенные индикаторы. Ставим по умолчанию — работает сразу |
| **OpenAI-совместимый** 💠 | варьируется | Любой сервис с API `/chat/completions`: **Groq (бесплатно)**, **OpenRouter (есть free-модели)**, **Gemini** (есть бесплатный тариф), Azure, DeepSeek и т.д. Нужен только ключ |
| **NeuroAPI** 🧠 | от $49.99/мес | Официальный API бота Neurobro (проприетарный, открытого кода нет) |

Если AI упал или ключ не задан — бот автоматически откатится на бесплатную стратегию, сигналы не остановятся.

## Установка на хостинг (bothost.ru / любой VPS с Ubuntu/Debian)

```bash
# 1. Кладём проект
mkdir -p /opt/po-signals-bot
# залить файлы в /opt/po-signals-bot (sftp / scp / панель)

# 2. Окружение
cd /opt/po-signals-bot
cp .env.example .env
nano .env   # вставить BOT_TOKEN (от @BotFather) и OWNER_ID (свой tg id)

# 3. venv + зависимости
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 4. systemd (автозапуск 24/7)
cp signalsbot.service /etc/systemd/system/signalsbot.service
systemctl daemon-reload
systemctl enable --now signalsbot
systemctl status signalsbot          # видим: active (running)
journalctl -u signalsbot -f          # логи
```

Проверка: напиши боту `/admin` → включи «⏯ Вкл / Выкл авто-сигналы» → нажми «🚀 Сигнал сейчас».

Обновление бота:
```bash
cd /opt/po-signals-bot && systemctl restart signalsbot
```

## Инструкция по настройке с нуля

1. **Токен** — @BotFather → `/newbot` → копируешь токен в `.env`.
2. **Свой ID** — @userinfobot → digits в `OWNER_ID`.
3. Запуск → `/admin` → ⚙️ **Настройки** → вписать:
   - 🔗 ссылку на Pocket Option (твоя аффил-ссылка),
   - 🎁 промокод,
   - 👤 свой контакт (@username) — юзеры «для ускорения» пишут тебе,
   - 💰 мин. депозит ($10 по умолчанию).
4. 📡 **Сигналы** → выбрать пару (BTCUSDT/ETHUSDT/... или свою), интервал, включить авто.
5. (Опционально) +💠: в ⚙️ Настройки вставить AI Key + Base URL + модель → 📡 **Сигналы** → 🤖 **AI-провайдер** → OpenAI-совместимый. Проверка кнопкой 🧪 **Тест AI**.

## Как юзер активируется

1. `/start` → читает 5 шагов, жмёт «📩 Отправить ID».
2. Присылает свой Pocket ID.
3. Тебе (и всем админам) прилетает уведомление с кнопками ✅/❌.
4. Жмёшь ✅ → юзер получает «🎉 Ты активирован» и начинает ловить сигналы.
5. ✅ депозит проверяешь глазами — кнопка только твоя по факту проверки.

## Ограничения

- Пары — крипта с публичных бирж (Binance/Bybit/OKX). OTC-пары Pocket Option не поддерживаются без их приватного WebSocket (это платный/рискованный путь, добавляем только если отдельно попросишь).
- Интервал сигналов ≥ 30 сек (защита от троттлинга).
- Торговля на бинарных опционах — это риск. Бот для образовательных целей, не является финансовой рекомендацией.
